## PROJECT OVERVIEW

Build a web-based Goal Setting & Tracking Portal for organizations. It manages the full lifecycle of employee goals — creation, manager approval, quarterly check-ins, and reporting.

## USER ROLES

There are exactly 3 roles. Every API route and UI screen must be protected by role.

1. EMPLOYEE
   - Can create, edit, and submit goal sheets (only before approval)
   - Can log quarterly achievement updates
   - Can view their own locked goals after approval
   - Cannot edit goals after manager approval

2. MANAGER (L1)
   - Has a team dashboard showing all direct reports
   - Can review submitted goals, edit targets/weightages inline before approving
   - Can approve or return goals for rework
   - Can conduct quarterly check-ins and add structured comments
   - Can push shared goals to multiple employees

3. ADMIN / HR
   - Can configure goal-setting cycles (open/close dates)
   - Can manage org hierarchy (who reports to whom)
   - Can unlock goals after the lock date (exception handling)
   - Has access to audit logs of all post-lock changes
   - Can view completion rates across the organization

## CORE BUSINESS LOGIC (never break these rules)

These are strict validation rules that must be enforced at BOTH the API level (Pydantic validators) and the frontend level (form validation):

1. Total weightage across all goals in a goal sheet MUST equal exactly 100%
2. Minimum weightage per individual goal is 10%
3. Maximum number of goals per employee per cycle is 8
4. Goals become LOCKED (no edits allowed) once the manager approves the goal sheet
5. After lock, any change must be made by Admin only and must be recorded in audit_logs
6. Shared goals: recipients can only change weightage — title and target are read-only
7. Achievement updates by the primary owner of a shared goal must sync to all linked employees automatically
8. Quarterly check-in windows are time-enforced — employees can only log achievements when the cycle phase is active

---

## PROGRESS SCORE FORMULAS (implement exactly)

When saving an achievement record, auto-compute progress_score based on uom_type:

- numeric_min (higher is better, e.g. Sales Revenue): progress_score = actual_value / target_value
- numeric_max (lower is better, e.g. TAT, Cost): progress_score = target_value / actual_value
- timeline (date-based): progress_score = 1.0 if completed on or before target_date, else partial based on delay
- zero (zero = success, e.g. Safety incidents): progress_score = 1.0 if actual_value == 0, else 0.0

Cap progress_score at 1.0 (100%) maximum. Store as a float between 0 and 1.

## API ROUTES TO BUILD

Auth:
POST /auth/login — returns JWT token
POST /auth/refresh — refresh token
GET /auth/me — returns current user info

Users (Admin only):
GET /users — list all users
POST /users — create user
PATCH /users/{id} — update user / reassign manager
GET /users/{id}/direct-reports — get team members

Goal Cycles (Admin only):
GET /cycles — list all cycles
POST /cycles — create cycle
PATCH /cycles/{id} — update cycle dates
POST /cycles/{id}/activate — set as active cycle

Goal Sheets (Employee):
POST /goal-sheets — create new goal sheet for active cycle
GET /goal-sheets/mine — get my goal sheets
POST /goal-sheets/{id}/submit — submit for manager approval
POST /goal-sheets/{id}/goals — add a goal to sheet
PATCH /goal-sheets/{id}/goals/{goal_id} — edit a goal (pre-approval only)
DELETE /goal-sheets/{id}/goals/{goal_id} — delete a goal (pre-approval only)

Manager Approval:
GET /manager/team-goals — get all submitted goal sheets from direct reports
PATCH /manager/goal-sheets/{id}/goals/{goal_id} — inline edit during review
POST /manager/goal-sheets/{id}/approve — approve and lock
POST /manager/goal-sheets/{id}/return — return for rework with comment

Shared Goals:
POST /admin/shared-goals — push a goal to multiple employees
PATCH /shared-goals/{id}/weightage — employee adjusts their weightage only

Achievements:
POST /achievements — log achievement for a goal in current phase
PATCH /achievements/{id} — update achievement
GET /goal-sheets/{id}/achievements — view all achievements for a sheet

Check-ins:
POST /checkins — manager posts a check-in comment
GET /checkins/{goal_sheet_id} — view all check-ins for a goal sheet

Reports (Manager + Admin):
GET /reports/achievement — full achievement report, supports CSV/Excel export
GET /reports/completion — who has and hasn't completed check-ins
GET /reports/audit-log — full audit trail (Admin only)
